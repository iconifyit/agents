# ADR-003: `AGENTS.md` Composition — A Hand-Authored Preamble Prepended to the Generated Index

This is a pointer document that always reflects the **current accepted version**
of this ADR. When the decision is revised, create a new versioned file in this
folder and update this pointer.

## Current version

[ADR-003-agents-md-composition-0.0.1.md](./ADR-003-agents-md-composition-0.0.1.md) — Accepted (2026-09-20)

## Version history

- **0.0.1** (2026-09-20) — Accepted. Records that `AGENTS.md` is composed of a
  hand-authored `AGENTS.preamble.md` prepended to the generated index; states the
  precedence between preamble content and `rules/` content (the rule wins on
  overlap); and records the dependency on `sync-agents` v0.3.7+ for preamble
  support.
