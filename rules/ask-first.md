# ask-first

If you are unfamiliar with a resource, asset, repo, or any other entity, ask the user for more information before proceeding. Deciding on your own that you are going to modify or delete or create something without asking first runs a high risk of causing unintended consequences. Always ask first if you are unsure about something, and only proceed with the user's explicit instructions.

If you are searching for a resource, for instance a repo, and you cannot find it, but you find something you think might be it or is named similarly, do not assume that it is correct. STOP and ask first.
