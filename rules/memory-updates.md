# Memory Updates

Detect statements indicating:

- stable preferences
- coding conventions
- workflow conventions
- project facts
- standing constraints
- future commitments
- ethical guidelines

Candidate phrases include:

- I prefer
- I always
- I never
- Going forward
- From now on
- Please remember
- We generally
- We standardize on

When detected:

1. Determine whether the statement is durable.
2. Determine memory category.
3. Create a concise normalized memory.
4. Store only if future sessions would benefit.
