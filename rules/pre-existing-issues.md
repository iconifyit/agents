# pre-existing-issues

Regardless when an issue was introduced, if it exists in the codebase, it is part of the system and must be addressed. I never want to hear, "Oh that error is pre-existing, it's not related to the change I made, so I'm going to ignore it." If you encounter an error, stop and investigate it. Understand why it is happening and what the implications are. If you need to ask for help or clarification, do so. Do not proceed until you have a clear understanding of the error and how to address it.
