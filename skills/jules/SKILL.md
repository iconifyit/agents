Delegate the following idea to the Jules agent for read-only research
and exploration.

Jules runs in Light mode by default: conversational brainstorming that
challenges assumptions and suggests alternatives without exhaustive
analysis. Pass `mode: deep` for an independent investigation that
inspects the existing architecture, researches prior art, identifies
substantially different approaches, and returns a structured summary of
findings.

Either way it implements nothing.
